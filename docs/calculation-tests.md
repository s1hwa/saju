## 2. 음수 시작점 오류에 대한 회귀 검증

- 음수 입력을 일괄적으로 1세 시작으로 바꾸면 원본의 절기·나이 대응이 달라지는 문제를 확인하고, 원본의 2년·3년 간격을 유지한 채 음수 구간을 제외하도록 수정함.

- 아래 입력별 첫 5개 나이를 기대값으로 지정하고, 이후 모든 계산 시점의 절기와 네 흐름 값도 입춘 기준의 주기 위치에 맞는지 확인함.

| 입력 입춘나이 | 기대하는 첫 표시 나이 5개 |
| ---: | --- |
| -1세 | 1 → 4 → 6 → 9 → 11세 |
| -2세 | 0 → 3 → 5 → 8 → 10세 |
| -3세 | 2 → 4 → 7 → 9 → 12세 |
| -4세 | 1 → 3 → 6 → 8 → 11세 |
| -5세 | 0 → 2 → 5 → 7 → 10세 |
| -16세 | 1 → 4 → 6 → 9 → 11세 |
| -103세 | 2 → 4 → 7 → 9 → 12세 |
| 0세 | 0 → 2 → 5 → 7 → 10세 |

- -103세 사례는 시작점 탐색이 기존 100년 오프셋 범위에 제한되지 않는지도 확인함.
