# Design System

## Character

시안 2-A "한지와 먹". 책력(冊曆)을 펼친 듯한 결과지. 한지 바탕, 먹 글씨, 인주(朱) 한 점, 이중 괘선 테두리로 사주 상담 본연의 품격을 살린다. 화면의 주인공은 고객명과 그래프이며, 설정과 내보내기는 조용하게 둔다. 붉은색은 낙관, 간지, 분석하기 버튼에만 쓴다. 로고는 선행원 올리브 배지(아래 Brand)로 따로 둔다.

## Typography

- 로컬 번들 폰트(`@fontsource`, 오프라인): Song Myung(제목·고객명·한자 절기·낙관), Nanum Myeongjo 400/700/800(본문·수치). 대체: Batang(바탕)
- 결과 고객명 34px Song Myung, 뒤의 "님의 인생 흐름"은 18px muted
- 입력 화면 제목 32px Song Myung, 자간 .06em
- 숫자에는 `font-variant-numeric: tabular-nums`
- ECharts `fontFamily`에는 따옴표를 쓰지 않는다. SVG 속성이 깨져 PNG·PDF 변환이 실패한다
- PNG 변환은 SVG 이미지라 문서 웹폰트를 못 쓰므로 Windows 바탕체로 대체된다

## 한자 표기 (`src/constants/hanja.ts`)

- 절기 한자(X축, 툴팁), 입춘 연도의 간지(`yearGanji`, 예: 1995 → 乙亥)
- 화면 표기 전용이며 계산에는 쓰지 않는다
- 간지는 입력 화면 연도 칸 옆, 결과 메타(立春 1995년 乙亥), 인주 낙관(`Seal`, 乙亥年生)에 표시

## Brand (선행원)

- 로고 A안: 둥근 사각(모서리 한 변의 16%) 올리브 배지 `#b4b27c` + 먹 테두리 안에 의뢰인 원본 얼굴 캐리커처. 도형은 `src/constants/logo.ts` 한 곳에 있다
- 크기별 세부 단계: 96px 이상 `full`(눈·코·턱), 36px 이상 `simple`(귀·안경·입), 24px 이상 `small`(얼굴·안경), 그 아래 `tiny`
- 상단 바: 배지 38px + 선행원(Song Myung 22px) + 구분선 + 인생 흐름 주기
- 입력 화면 하단 서명줄: 상호 · 슬로건 · 서비스 · 상담자 연락처 (흐름 밖에 두어 폼 가운데 정렬을 흔들지 않는다)
- 상호 문구는 `src/constants/config.ts`의 `BRAND_*`
- 실행 아이콘: `node scripts/run-electron.cjs scripts/render-icon.cjs`로 `build/icon.ico`(16–256)·`icon.png`를 다시 만든다
- 창 제목: 선행원 · 인생 흐름 주기

## Shape and Spacing

- 모서리는 각지게: 패널·입력·토글 0, 버튼 2px
- 패널은 이중 괘선(1px 테두리 + 3px 간격 outline), 상단 바는 3px double 괘선
- 그림자는 쓰지 않는다
- 컨트롤 높이: 32(보조), 36(기본), 38(흐름 토글), 46–50(입력·분석하기)
- 결과 화면 최대 폭 1640px, 좌우 여백 28px

## Buttons

- 1차: 인주 배경 (`분석하기`)
- 윤곽(먹선): `새 상담`. 입력을 초기화하는 동작이라 수정과 모양을 다르게 둔다
- 조용한 텍스트: `정보 수정`, `전체 보기/화면 맞춤`
- 내보내기: PDF · 인쇄 · PNG를 하나의 분절 그룹으로 묶어 고객 정보 오른쪽에 둔다
- 아이콘 단독 버튼(`이전 구간`, `다음 구간`)에는 `aria-label`과 `title`을 둔다

## Screens

### 입력

- 가운데 680px 열: 작은 상태 라벨 → 제목 → 3행 입력표 → 하단 바(오류/Enter 안내 + 분석하기)
- 각 행은 왼쪽 라벨·설명, 오른쪽 입력. 숫자 입력에는 `년`, `세` 단위를 붙인다
- 오류는 해당 행을 빨간 테두리로 표시하고 그 입력에 포커스를 옮긴다
- 정보 수정 상태에서는 제목이 바뀌고 `결과로 돌아가기`, `다시 분석`이 나타난다
- 표 아래에 분석 기준(흐름 항목, 간격, 시점, 축 기준)을 한 줄로 조용히 보여준다

### 결과

- 상단 바: 상호 | 정보 수정, 새 상담
- 고객 영역: 이름 + 입춘 기준 · 나이 · 상담일 | 내보내기 그룹과 처리 상태
- 그래프 패널: 흐름 토글(왼쪽) | 현재 구간, 이전·다음, 전체 보기(오른쪽) → 그래프 → 구간 슬라이더

## Chart

- ECharts + SVG 렌더러, `smooth: 0.32`(smoothMonotone 없음), 원본 데이터 지점에 속 빈 표식 표시
- 선 1.9px, 가로 보조선 실선 `#dccfb2`, 세로 괘선 옅게, 0 기준선 muted
- 같은 기울기로 이어지는 구간은 직선, 방향이 바뀌는 꼭짓점만 완만하게 둥글린다. `smoothMonotone: 'x'`는 점마다 선을 눌러 계단처럼 보이게 하므로 쓰지 않는다
- 꼭짓점 좌우 값이 같아 접선이 수평이 되므로 곡선이 최댓값·최솟값을 넘지 않는다
- Y축 -12.5 ~ +22.5, 보조선 2.5 간격, 라벨은 5 단위, 0 기준선은 진하게
- X축 라벨: 한자 절기(Song Myung) / 연도 / 나이 3줄
- 탐색: 첫 화면은 라벨이 읽히는 폭(점당 34px 이상)만큼 보여준다. 1440px에서는 38개 전체, 1100px에서는 28개
  - 하단 슬라이더 드래그, 그래프 드래그·휠 이동, Ctrl+휠 확대
  - 이전·다음 버튼은 보이는 구간의 절반씩 이동
  - 전체 보기에서 점 간격이 좁으면 라벨만 일정 간격으로 건너뛴다
- 라벨·툴팁은 카테고리 값(배열 위치)으로 시점을 찾는다. formatter의 `index`는 확대 구간 기준이라 쓰지 않는다
- `prefers-reduced-motion`이면 그래프 애니메이션을 끈다

## Export

- 내보내기용 그래프는 화면 확대 상태와 무관하게 1400×660 오프스크린 차트로 38개 전체를 그린다
- PNG: 고객명·입춘 기준·범례를 그림 안에 포함, 배경 `#fbf6ea`
- PDF·인쇄: A4 가로 결과지. 로고 배지·선행원·슬로건 | 결과지 이름·상담일(이중 괘선) → 고객명·메타·낙관 → 표시 항목 → 이중 괘선 그래프 → 꼬리말(상호·서비스·상담자·연락처)
- PNG·결과지 그래프 이미지 오른쪽 아래에 '선행원'을 작게 적는다
- 앱 내비게이션과 버튼은 출력하지 않는다

## Verification

`npm run capture:ui`는 모션 축소 모드로 다음을 캡처하고 검증한다.

- 입력, 입력 오류, 정보 수정(입력 보존 확인)
- 심리만 선택된 초기 결과(선택 상태 확인), 네 흐름 전체, 빈 상태
- 1100×720 맞춤 · 다음 구간(X축 라벨과 범위 일치 확인) · 전체 보기, 1920×1080
- `export-graph.png`, `report.pdf`
- 렌더러 콘솔 오류가 있으면 실패
