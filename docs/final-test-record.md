## 2. 최근 코드 수정 후 검증 기록

- 음수 시작점 수정 후 `npm test`, `npm run typecheck`, `npm run build`가 모두 통과함.

- 2026.10.11. 체크리스트 전용 테스트를 추가하여 기존 42개와 신규 36개, **총 78개 자동 테스트가 통과함.** 실제 프린터·고객 PC 검증 2개는 건너뜀으로 구분함.

- PDF는 실제 A4 가로 크기, 고객 텍스트·그래프 이미지 포함, 콘텐츠의 페이지 내부 배치를 검사하고 렌더링 미리보기도 확인함.
