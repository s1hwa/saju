## 2. 최근 코드 수정 후 검증 기록

- 음수 시작점 수정 후 `npm test`, `npm run typecheck`, `npm run build`가 모두 통과함.

- 2026.10.11. 체크리스트 전용 테스트를 추가하여 기존 42개와 신규 36개, **총 78개 자동 테스트가 통과함.** 실제 프린터·고객 PC 검증 2개는 건너뜀으로 구분함.

- 최신 로컬 빌드를 네트워크 차단 상태에서 실행해 **Electron 화면 테스트 9개가 통과함.** 입력 오류·기본 흐름 선택·구간 이동·정보 수정·음수 시작점 표시·인쇄용 PNG 생성·PDF 1페이지 출력을 확인함.

- PDF는 실제 A4 가로 크기, 고객 텍스트·그래프 이미지 포함, 콘텐츠의 페이지 내부 배치를 검사하고 렌더링 미리보기도 확인함.

<br>

## 3. 검증 범위와 남은 확인

- 자동 테스트는 계산 함수와 차트·결과지 구성을 검사함. 실제 Excel 프로그램을 실행해 매번 결과를 대조하는 방식은 아님.
- PNG 검증은 인쇄용 그래프 이미지 생성에 대한 검사이며, 파일 저장 대화상자 조작까지 검증한 것은 아님.
- 실제 프린터 출력·고객 PC 설치·파일 저장 대화상자·마우스 휠 및 드래그 조작은 최근 검증에 포함되지 않음.
- 최근 계산 수정 후 배포용 설치 파일은 재생성하지 않음. 네트워크 차단 상태의 로컬 빌드 실행과 고객 PC 설치 파일 검증은 구분함.
- 항목별 검증 방법과 수동 확인 사례는 [체크리스트 검증 기록](verification-checklist.md), 계산 테스트 상세는 [계산 로직 자동 테스트](calculation-tests.md)에서 확인할 수 있음.
