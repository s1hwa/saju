# 인생 흐름 주기

saju - life flow graphs

기존 Excel 기반 상담 도구를 가게에서 사용하는 오프라인 Windows 프로그램으로 재구현한 프로젝트입니다. Excel의 계산 기준을 분석하고, 의뢰인과 합의한 그래프 시작점 개선을 반영했습니다.

## 1. 문제

### 의뢰인이 지적한 문제 및 요구사항

- 기존 Excel 도구에서는 원하는 기준으로 그래프 시작점을 고정하기 어려워, `-16세` 등 음수 나이부터 표시되는 문제가 있었습니다.
- 필요한 흐름을 보여주려면 Excel 행을 직접 숨기거나 표시해야 했습니다.
- 기존에는 네 개 시트에 그래프가 분리돼 있어 각 흐름을 따로 확인해야 했으며, 네 흐름의 관계를 한눈에 비교하기 어려웠습니다.
- Excel 셀 중심의 화면을 고객에게 보여줄 수 있는 전문적인 상담 화면으로 개선해야 했습니다.
- 절기·연도·나이를 함께 확인하고, 심리·수단·재물·명예를 개별적으로 표시할 수 있어야 했습니다.
- 결과를 PDF·이미지로 저장하거나 인쇄해 고객에게 제공할 수 있어야 했습니다.
- 기존 계산 기준을 유지하면서 합의한 개선사항을 반영해야 했습니다.

### 개발 중 발견한 문제

- **원본 데이터 개수 불일치:** 첫 번째 시트의 시점 정보는 38개, 흐름 값은 39개였습니다. 같은 열끼리 연결하면 초기 값과 흐름 시작 시점이 달라졌습니다.
- **작동하지 않는 간격 설정:** 간격 년수 셀은 첫 번째 시트 수식에서 참조되지 않았습니다. 셀 값 변경만으로 흐름 간격이 바뀌는 구조가 아니었습니다.
- **연도 기준 혼동:** 시작점 보정 과정에서 생년까지 이동시키면 연도와 나이의 관계가 어긋날 수 있었습니다. 2003년생·입춘 나이 -16세 사례를 회귀 테스트로 보호했습니다.
- **입춘 위치 불일치:** 이전 구현에서는 입춘 나이 7세를 입력해도 입춘 지점에 8세가 표시됐습니다.
- **탐색 막대 위치 오류:** 입춘 나이 4·9·14세 등의 경우, 음수 시점을 숨긴 뒤 범위 막대가 오른쪽으로 치우쳐 보였습니다.
- **확대 구간의 라벨 대응:** 확대 구간의 상대 인덱스로 라벨을 찾으면 실제 시점과 다른 정보를 표시할 수 있었습니다.
- **이미지 변환 실패:** 그래프 폰트 설정의 따옴표가 SVG 속성을 깨뜨려 PNG 및 PDF용 그래프 변환에 실패하는 문제가 기록돼 있었습니다.
- **초기 화면의 사용성:** 불필요한 장식과 넓은 빈 공간, 단순 가로 스크롤 때문에 상담 정보와 주요 시점에 집중하기 어려웠습니다.

## 2. 해결을 위한 판단

- 의뢰인이 고령의 소상공인이고 인터넷 사용에 익숙하지 않다는 점을 고려해 접속·로그인 절차를 줄이기로 했습니다.
- 본인 가게의 Windows PC에서만 사용하므로 인터넷과 서버 없이 실행하는 설치형 프로그램을 선택했습니다. Windows 실행 파일은 의뢰인의 지정 요구가 아닌, 사용 환경을 고려한 개발자의 판단입니다.
- 생년·입춘 나이·표시 시작점을 구분했습니다. 내부 계산에 필요한 음수 시점은 유지하되 화면에서는 제외했습니다.
- 표시 구간과 원본 데이터의 인덱스를 변환해 그래프·툴팁·탐색 막대가 같은 시점을 가리키도록 구성했습니다.
- 간격 설정은 사용자 입력에서 제외하고 현재의 10년 기준으로 관리했습니다.
- 계산 로직과 화면을 분리하고, PDF·인쇄에는 별도의 결과지 레이아웃을 사용했습니다.
- 분리된 네 그래프를 한 화면에 통합하고, 필요한 흐름을 개별 선택하거나 네 흐름을 동시에 비교할 수 있도록 구성했습니다.
- 상담 화면의 전문성을 높이기 위해 연도 입력 시 해당 연도의 간지를 한자로 표시하도록 했습니다. 예를 들어 1995년은 `乙亥`(을해년)로 표시하며, 이 표기는 흐름 계산과 분리했습니다.

### 사용 기술과 선택 이유

| 기술 | 선택 이유 |
| --- | --- |
| React | 입력·결과·출력 화면을 분리하고 흐름 선택 상태를 관리하기 위해 사용했습니다. |
| TypeScript | 연도·나이·절기·흐름 데이터의 구조와 계산 계약을 명확히 정의하기 위해 사용했습니다. |
| Electron | Windows 설치형 실행과 로컬 저장·PDF·인쇄 기능을 제공하기 위해 선택했습니다. |
| Apache ECharts | 흐름별 표시·숨김, 툴팁, 구간 확대·이동을 구현하기 위해 사용했습니다. |
| Vite | 개발 환경과 배포용 화면 빌드를 구성하기 위해 사용했습니다. |

## 3. 판단의 근거

- 사용 장소와 사용자가 한정돼 있어 계정 관리와 중앙 서버의 필요성이 낮았습니다.
- 설치 후 바로 실행하는 방식이 의뢰인의 인터넷 조작 부담을 줄일 수 있다고 판단했습니다.
- 시작점의 라벨만 바꾸면 계산 관계가 어긋나므로 연도·나이·절기 정렬을 함께 검증해야 했습니다.
- 원본 참조 범위와 수식을 분석해 데이터 개수 불일치와 간격 설정의 미참조 사실을 확인했습니다.
- 초기 Excel 이식에서는 사용자 승인에 따라 시점 정보 `C:AN`과 흐름 값 `B:AM`을 연결하고, 대응 시점이 없는 마지막 값을 문서에 남겼습니다.
- 이후 시작점과 주기 개선이 반영된 현재 코드는 41개 시점을 계산합니다. 초기 38개 시점 분석과 현재 계산 규칙을 구분해야 합니다.
- 계산과 표시 구간을 분리하면 화면을 개선하면서 계산 규칙을 독립적으로 검증할 수 있습니다.
- 네 흐름을 같은 축에서 보여주면 시트를 전환하지 않고 같은 시점의 차이를 비교할 수 있습니다.
- 연도에 한자 간지를 함께 표시하면 상담 분야에 맞는 정보를 제공하면서 화면의 전문성을 더할 수 있다고 판단했습니다. 간지는 표시용 정보로 사용해 흐름 계산에 영향을 주지 않도록 했습니다.

관련 기록: [Excel 분석](docs/excel-analysis.md), [판단 기록](docs/decision-log.md), [화면 재설계 기준](docs/ui-redesign-handoff.md). 초기 문서의 시점 수와 계산 설명은 현재 코드와 차이가 있으므로 변경 시점을 함께 확인해야 합니다.

## 4. 결과

- `-16세` 입력 사례에서도 생년의 `1세`부터 그래프가 표시되도록 개선했습니다.
- 입력 규칙에 따라 `0세` 또는 `1세`부터 표시하고, 입춘 지점이 입력한 입춘 나이에 대응하도록 수정했습니다.
- 탐색 범위와 라벨을 표시 시작점에 맞춰 연결했습니다.
- 화면 확대 상태와 별도로 출력용 그래프를 생성하도록 구성했습니다.
- 심리·수단·재물·명예 개별 선택, 정보 수정·새 상담, PDF·PNG 저장·인쇄 기능을 구현했습니다.
- 네 시트에서 따로 보던 심리·수단·재물·명예 그래프를 한 화면에서 동시에 확인하고 비교할 수 있도록 개선했습니다.
- 연도를 입력하면 한자 간지가 자동 표시되도록 구현했습니다. 예를 들어 `1995년 → 乙亥(을해년)`이며, 입력 화면·결과 화면·결과지에 반영했습니다.
- Windows 설치형 실행 방식을 적용하고 소스 코드를 GitHub에 업로드했습니다.

## 5. 검증기준 및 검증 결과

| 검증 항목 | 기준 | 확인 결과 |
| --- | --- | --- |
| 시작점 | 음수 입춘 나이에서도 생년의 1세부터 표시 | 해당 자동 테스트 통과 |
| 연도 정확성 | 시작점 보정으로 생년이 이동하지 않을 것 | 2003년·입춘 나이 -16세 회귀 테스트 통과 |
| 입춘 정렬 | 입력한 입춘 나이와 입춘 지점이 일치 | 입춘 나이 1~15세 테스트 통과 |
| 표시 구간 | 화면에 표시할 구간에 음수 나이가 없을 것 | 해당 자동 테스트 통과 |
| 계산 관계 | 연도·나이 정렬, 주기 반복, 흐름 간격 유지 | 해당 자동 테스트 통과 |
| 화면 탐색 | 확대·이동 후 라벨·툴팁·범위 막대 일치 | 실제 화면 재검증 결과 기록 필요 |
| 설치 및 실행 | 대상 PC에서 설치 후 오프라인 실행 | 현장 검증 결과 기록 필요 |
| 출력 품질 | PDF·PNG·인쇄에서 정보 누락과 잘림이 없을 것 | 출력 검증 결과 기록 필요 |

- **자동 검증 결과:** 2026-10-11 `npm test` 실행에서 1개 테스트 파일, 34개 테스트가 모두 통과했습니다.
- 자동 테스트 통과는 계산 규칙에 대한 확인이며, 실제 설치·화면 렌더링·프린터 출력까지 검증했다는 의미는 아닙니다.

## 6. 배포 후 수정 및 개선

### 기록된 수정사항

- 사용자 안내서에는 2026-10-01 밤부터 10-02 새벽까지의 수정사항이 기록돼 있습니다.
- 시작 절기 직접 선택을 입춘 나이 입력과 자동 계산 방식으로 변경했습니다.
- 생년이 항상 1세가 되는 해로 유지되도록 기준을 정리했습니다.
- 시작 나이 자동 조정, 입춘 위치 불일치, 탐색 막대 치우침을 수정했습니다.
- 고객 정보에서 불필요한 표시 시작 문구를 제거했습니다.
- 상호·로고·실행 아이콘·결과지 브랜딩을 적용하고 입력 화면을 정리했습니다.
- 이 변경들이 어느 배포 이후에 적용됐는지는 배포 버전과 전달 날짜를 대조해 확정해야 합니다.

### 향후 개선 및 관리 기준

- 현장 피드백에 따라 글자 크기·버튼 배치·그래프 탐색·출력물 가독성을 개선합니다.
- 수정마다 발생 상황·원인·변경 내용·적용 버전·재검증 결과를 기록합니다.
- 초기 분석 문서와 현재 계산 규칙의 차이를 정리해 유지보수 시 혼동을 줄입니다.

## README 이미지 추가

- 게시할 이미지는 `docs/images/`에 저장합니다. `artifacts/`는 Git 추적에서 제외되므로 해당 경로를 직접 연결하지 않습니다.
- 각 이미지 위치의 HTML 주석에 권장 파일명과 캡처 내용이 적혀 있습니다. 파일을 준비한 뒤 해당 이미지 문장을 주석 밖으로 옮기면 GitHub에 표시됩니다.
- 기존 Excel과 개선된 그래프는 동일한 입력으로 비교하고, 고객 이름·연락처 등 개인정보는 가립니다.
- 기존 캡처가 현재 코드의 화면과 일치하는지 확인한 뒤 사용합니다.
