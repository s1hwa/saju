# 인생 흐름 주기


사주 상담소에서 사용하는 Windows용 인생 흐름 상담 프로그램. 고객의 이름·입춘 기준년도·나이를 입력하면 기존 Excel 규칙에 따라 심리·수단·재물·명예의 흐름을 자동 계산하고, 절기·연도·나이와 함께 그래프로 표시. 네 흐름의 통합 비교와 개별 선택, 상담 결과의 PDF·PNG 저장 및 인쇄 지원. 인터넷 연결이나 Microsoft Excel 설치 없이 가게 PC에서 독립 실행.

의뢰의 주된 목적은 기존 Excel의 계산 정확성을 유지하면서 셀 입력·행 숨김·표시 등의 수작업을 간편한 상담 과정으로 전환하는 것. 고객에게 보여줄 전문적이고 읽기 쉬운 결과 화면을 제공하고, 상담부터 결과지 전달까지의 편의성 개선. Excel 계산 기준 분석과 의뢰인과 합의한 그래프 시작점 개선 반영.

## 1. 문제

### 의뢰인이 지적한 문제 및 요구사항

- 그래프 시작점 고정이 어려워 `-16세` 등 음수 나이부터 표시되는 문제 발생.
- 필요한 흐름을 표시하기 위해 Excel 행을 직접 숨기거나 표시하는 수작업 필요.
- 네 개 시트에 분리된 그래프로 인해 흐름별 확인과 관계 비교에 어려움 발생.
- Excel 셀 중심 화면을 고객에게 보여줄 전문적인 상담 화면으로 개선 필요.
- 절기·연도·나이 동시 표시 및 심리·수단·재물·명예 개별 표시 요구.
- 고객에게 제공할 결과의 PDF·이미지 저장 및 인쇄 요구.
- 기존 계산 기준 유지와 합의한 개선사항 반영 요구.

### 개발 중 발견한 문제

- **원본 데이터 개수 불일치:** 첫 번째 시트의 시점 정보 38개, 흐름 값 39개로 개수 불일치 발견. 같은 열끼리 연결할 경우 초기 값과 흐름 시작 시점의 차이 발생.
- **작동하지 않는 간격 설정:** 첫 번째 시트 수식에서 간격 년수 셀을 참조하지 않는 구조 발견. 셀 값 변경만으로 흐름 간격 조정 불가.
- **연도 기준 혼동:** 시작점 보정 시 생년까지 이동하면 연도·나이 관계가 어긋나는 문제 발견. 2003년생·입춘 나이 -16세 사례의 회귀 테스트 추가.
- **입춘 위치 불일치:** 입춘 나이 7세 입력 시 입춘 지점에 8세가 표시되는 오류 발견.
- **탐색 막대 위치 오류:** 입춘 나이 4·9·14세 등에서 음수 시점을 숨긴 뒤 범위 막대가 오른쪽으로 치우치는 오류 발견.
- **확대 구간의 라벨 대응:** 상대 인덱스로 라벨을 조회할 경우 실제 시점과 다른 정보가 표시되는 문제 발견.
- **이미지 변환 실패:** 그래프 폰트 설정의 따옴표로 인한 SVG 속성 손상과 PNG·PDF용 그래프 변환 실패 기록 확인.
- **초기 화면의 사용성:** 불필요한 장식·넓은 빈 공간·단순 가로 스크롤로 인해 상담 정보와 주요 시점의 가독성 저하.

## 2. 해결을 위한 판단

- 고령의 소상공인인 의뢰인의 인터넷 사용 부담을 고려해 접속·로그인 절차 최소화.
- 가게의 Windows PC 사용 환경을 고려해 인터넷·서버 없이 실행하는 설치형 프로그램 선택. Windows 실행 파일 제공은 사용 환경을 고려한 개발자의 판단.
- 생년·입춘 나이·표시 시작점 구분. 내부 계산에 필요한 음수 시점은 유지하고 화면 표시에서 제외.
- 표시 구간과 원본 데이터의 인덱스를 변환해 그래프·툴팁·탐색 막대의 시점 일치 구현.
- 간격 설정은 사용자 입력에서 제외하고 10년 기준으로 관리.
- 계산 로직과 화면 분리 및 PDF·인쇄 전용 결과지 레이아웃 적용.
- 네 그래프를 한 화면에 통합하고 개별 선택과 동시 비교 기능 구성.
- 상담 화면의 전문성을 높이기 위해 연도별 한자 간지 표시 적용. `1995년 → 乙亥(을해년)` 표기는 흐름 계산과 분리.

### 사용 기술과 선택 이유

| 기술 | 선택 이유 |
| --- | --- |
| React | 입력·결과·출력 화면 분리 및 흐름 선택 상태 관리. |

| Vitest | 화면 실행 없이 시작점·연도·절기·주기 관계 자동 검증. |

## 3. 판단의 근거

- 사용 장소와 사용자가 한정돼 계정 관리와 중앙 서버의 필요성 낮음.
- 설치 후 바로 실행하는 방식으로 의뢰인의 인터넷 조작 부담 감소 기대.
- 시작점 라벨만 변경할 경우 계산 관계가 어긋나므로 연도·나이·절기 정렬의 동시 검증 필요.
- 원본 참조 범위와 수식 분석을 통해 데이터 개수 불일치 및 간격 설정 미참조 확인.
- 초기 Excel 이식 시 사용자 승인에 따라 시점 정보 `C:AN`과 흐름 값 `B:AM` 연결. 대응 시점이 없는 마지막 값은 문서에 기록.
- 시작점과 주기 개선을 반영한 현재 코드의 계산 시점은 41개. 초기 38개 시점 분석과 현재 계산 규칙의 구분 필요.
- 계산과 표시 구간 분리로 화면 개선과 계산 규칙의 독립 검증 가능.
- 동일한 축에 네 흐름을 표시해 시트 전환 없이 같은 시점의 차이 비교 가능.
- 한자 간지 표시로 상담 분야에 맞는 정보 제공과 화면 전문성 향상 기대. 흐름 계산에 영향을 주지 않는 표시용 정보로 관리.

관련 기록: [Excel 분석](docs/excel-analysis.md), [판단 기록](docs/decision-log.md), [화면 재설계 기준](docs/ui-redesign-handoff.md). 초기 문서의 시점 수·계산 설명과 현재 코드 간 차이가 있으므로 변경 시점 확인 필요.

## 4. 결과

- `-16세` 입력 사례에서도 생년의 `1세`부터 그래프가 표시되도록 개선.
- 입력 규칙에 따라 `0세` 또는 `1세`부터 표시하고, 입력한 입춘 나이와 입춘 지점이 대응하도록 수정.
- 탐색 범위와 라벨을 표시 시작점에 맞춰 연결.
- 화면 확대 상태와 별도로 출력용 그래프 생성.
- 심리·수단·재물·명예 개별 선택, 정보 수정·새 상담, PDF·PNG 저장·인쇄 기능 구현.
- 네 시트에 분리된 심리·수단·재물·명예 그래프의 통합 표시 및 동시 비교 구현.
- 연도 입력 시 한자 간지 자동 표시 구현. `1995년 → 乙亥(을해년)` 표기를 입력 화면·결과 화면·결과지에 반영.
- Windows 설치형 실행 방식 적용 및 소스 코드 GitHub 업로드.

## 6. 배포 후 수정 및 개선

### 기록된 수정사항

- 사용자 안내서에서 2026-10-01 밤부터 10-02 새벽까지의 수정사항 기록 확인.
- 시작 절기 직접 선택에서 입춘 나이 입력·자동 계산 방식으로 변경.
- 생년이 항상 1세가 되는 해로 유지되도록 기준 정리.
- 시작 나이 자동 조정, 입춘 위치 불일치, 탐색 막대 치우침 수정.
- 고객 정보에서 불필요한 표시 시작 문구 제거.
- 상호·로고·실행 아이콘·결과지 브랜딩 적용 및 입력 화면 정리.
- 변경사항의 적용 배포 시점은 배포 버전·전달 날짜 대조 후 확정 필요.

### 향후 개선 및 관리 기준

- 현장 피드백에 따른 글자 크기·버튼 배치·그래프 탐색·출력물 가독성 개선.
- 수정별 발생 상황·원인·변경 내용·적용 버전·재검증 결과 기록.
- 초기 분석 문서와 현재 계산 규칙의 차이 정리로 유지보수 시 혼동 방지.

## README 이미지 추가

- 게시할 이미지는 `docs/images/`에 저장. `artifacts/`는 Git 추적에서 제외되므로 README 직접 연결 대상에서 제외.
- `npm run build` 후 `npm run capture:ui`로 현재 화면과 PDF를 `artifacts/`에 생성. 확인한 캡처를 `docs/images/`로 복사해 README에 연결.
- 미준비 비교 이미지의 권장 파일명·캡처 내용은 HTML 주석에 기록. 파일 준비 후 이미지 문장을 주석 밖으로 이동해 GitHub에 표시.
- 기존 Excel과 개선된 그래프는 동일한 입력으로 비교하고, 고객 이름·연락처 등 개인정보는 가림 처리.
- 기존 캡처와 현재 코드의 화면 일치 여부 확인 후 사용.
