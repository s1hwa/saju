## 2. 핵심 문제 해결

<br>

### 2-1. Excel 시점 정보와 흐름 값의 불일치 분석

<br>

#### 2-1-1. 문제 정의 및 원인 파악

- 첫 번째 시트의 절기·연도·나이 정보는 `C:AN`의 38개인데, 흐름 값은 `B:AN`의 39개로 개수와 시작 열이 달랐음.

- 같은 열끼리 연결하면 첫 흐름 값이 누락되고 시점과 값의 대응이 어긋남.


<br>

![Excel 원본의 1950년과 -16세 및 심리 값으로 비교한 데이터 연결 예시](docs/images/excel-point-mismatch.png)

<br>

#### 2-1-2. 해결 과정

##### 1. 초기 이식의 시점과 흐름 값 연결 수정

- 초기에는 Excel의 시점 정보와 흐름 값의 개수·시작 위치를 맞추는 작업을 진행

- 같은 열끼리 연결하면 첫 번째 흐름 값이 빠지므로, 첫 번째 시점인 C열에 첫 번째 흐름 값인 B열을 연결하고, 다음 시점인 D열에는 C열의 값을 연결하는 방식으로 순서를 맞춤.

- 대응할 시점이 없는 마지막 AN열의 흐름 값은 의뢰인과 합의해 제외함.

<br>

##### 2. 주기 계산 방식 변경 및 표시 범위 확장

- 기존 방식은 Excel에 저장된 38개 흐름 값만 사용해, 입춘나이에 따른 시작점 조정과 표시 범위 확장에 한계가 있었음.
  
- 이를 해결하기 위해 심리 흐름의 첫 24개 값을 반복하는 규칙을 적용하고, 수단·재물·명예는 각각 4·8·12칸씩 이동해 계산하도록 변경함. 이를 통해 네 흐름 간 10년 간격을 유지함.

- 입춘나이가 9세인 경우, 1·4·6·9세를 동지·소한·대한·입춘에 연결하고 해당 절기의 흐름 값을 계산해, 시작 나이뿐 아니라 절기와 흐름 값도 함께 조정하도록 구현함.

- 또한 기존 38개 시점(92년 범위)에 95·97·100년을 추가해 총 41개 시점(100년 범위)으로 확장하고, 추가 구간의 값도 반복 규칙으로 계산함.


<br>

#### 2-1-3. 결과

- 초기 데이터의 대응 오류를 해결하고, 현재는 41개 시점을 계산하면서 24절기 주기 반복과 흐름 간 10년 간격을 유지함.

- 결과적으로 Excel 값의 단순 조회 방식에서 주기 기반 계산 방식으로 전환하여, 입춘 이전과 원본 범위 이후까지 일관된 흐름을 표시할 수 있게 됨. 

- 초기 38개 이식 기준과 현재 41개 계산 기준은 [초기 판단 기록](docs/decision-log.md),  [주기 데이터](src/constants/cycleData.ts), [계산 테스트](src/logic/calculateConsultation.test.ts)로 구분해 확인할 수 있음.

<br><br>

### 2-2. 절기 주기에 의한 시작 나이 통일 불가 문제

<br>

#### 2-2-1. 문제 정의 및 원인 파악

- 의뢰인은 기존 그래프를 모든 경우에 1세부터 표시하기를 요청함.

- 그러나 절기가 2.5년 주기로 반복되어 시작 나이를 일괄적으로 1세로 설정하면, 입력한 입춘 나이가 입춘 지점에 놓이지 않는 경우가 발생함.

- 실제로 입춘 나이 7세를 입력했을 때 입춘 지점에 8세가 표시되는 오류를 확인

<br>

![모든 그래프 1세 표시 요구에 따른 -16세 시작점 보정과 9세 음수 숨김 과정](docs/images/spring-age-alignment.png)

<br>

#### 2-2-2. 해결 과정

- 입춘 지점에 입력 나이가 정확히 대응하도록 시작 나이를 정하고, 음수 지점의 화면 노출 여부는 별도로 처리하기로 의뢰인과 협의함.

- 양수 입춘 나이는 5로 나눈 나머지에 따라 1·0·-1세 중 하나에서 계산을 시작함.

| 입력한 입춘 나이 | 내부 계산 시작 | 화면 표시 시작 |
| --- | --- | --- |
| 양수이며 5로 나눈 나머지가 1·3: 1·3·6·8·11·13세 등 | 1세 | 1세 |
| 양수이며 5로 나눈 나머지가 0·2: 2·5·7·10·12·15세 등 | 0세 | 0세 |
| 양수이며 5로 나눈 나머지가 4: 4·9·14·19세 등 | -1세 | 음수 지점을 제외하고 1세 |
| -16세 | 원본의 음수 구간 이후 1세 | 1 → 4 → 6 → 9세 |
| -3세 | 원본의 음수 구간 이후 2세 | 2 → 4 → 7 → 9세 |
| -2세·0세 | 원본에서 처음 0세 이상이 되는 시점 | 0 → 3 → 5세 / 0 → 2 → 5세 |

- 예를 들어 입춘 나이가 -16세이면 원본 순서 `-16 → -14 → -11 → -9 → -6 → -4 → -1 → 1 → 4 → 6 → 9세`에서 음수 구간을 제외하고, 소만부터 `1 → 4 → 6 → 9세`를 표시함.

- 음수 지점을 숨긴 뒤에도 그래프·툴팁·탐색 막대가 같은 시점을 가리키도록 내부 인덱스와 표시 인덱스를 변환함.

<br>

#### 2-2-3. 결과

- 협의한 기준에 따라 일부 경우에는 0세를 표시하고, -1세에서 계산하는 경우에는 음수 지점을 숨겨 1세부터 표시하도록 구현함.

- 적용 규칙과 검증 사례는 [계산 로직](src/logic/calculateConsultation.ts), [화면 표시](src/components/FlowChart.tsx), [계산 테스트](src/logic/calculateConsultation.test.ts)에서 확인할 수 있음.

| 이름 입력 처리 | 이름 앞뒤 공백을 제거하고 입력 연도·나이를 유지함을 확인 | 1 |
| **합계** | **계산 로직 자동 테스트** | **42** |

<br>

#### 4-2-1. 음수 시작점 오류에 대한 회귀 검증

- 음수 입력을 일괄적으로 1세 시작으로 바꾸면 원본의 절기·나이 대응이 달라지는 문제를 확인하고, 원본의 2년·3년 간격을 유지한 채 음수 구간을 제외하도록 수정함.

- 아래 입력별 첫 5개 나이를 기대값으로 지정하고, 이후 모든 계산 시점의 절기와 네 흐름 값도 입춘 기준의 주기 위치에 맞는지 확인함.

| 입력 입춘나이 | 기대하는 첫 표시 나이 5개 |
| ---: | --- |
| -1세 | 1 → 4 → 6 → 9 → 11세 |
| -2세 | 0 → 3 → 5 → 8 → 10세 |
| -3세 | 2 → 4 → 7 → 9 → 12세 |
| -4세 | 1 → 3 → 6 → 8 → 11세 |
| -5세 | 0 → 2 → 5 → 7 → 10세 |
| -16세 | 1 → 4 → 6 → 9 → 11세 |
| -103세 | 2 → 4 → 7 → 9 → 12세 |
| 0세 | 0 → 2 → 5 → 7 → 10세 |

- -103세 사례는 시작점 탐색이 기존 100년 오프셋 범위에 제한되지 않는지도 확인함.

### 4-4. 최근 수정의 검증 범위

## 5. 성과 및 의뢰인 피드백

<br>

### 5-1. 추가된 기능과 개선 성과

| 추가·개선한 기능 | 개선된 업무 |
| --- | --- |
| 심리·수단·재물·명예 통합 그래프와 개별 선택 | 네 시트의 그래프를 한 화면에서 비교하고, Excel의 행 숨김·표시 작업을 흐름 선택으로 대체함 |
| 시작 나이 보정과 음수 시점 숨김 | 합의한 기준에 따라 0세 또는 1세부터 표시하여 상담에 필요한 구간을 보여줌 |
| PDF·PNG 저장과 인쇄 | 손으로 그래프를 그려 카카오톡으로 보내던 작업을 결과지 저장 후 전송하는 방식으로 개선함 |
| 연도별 한자 간지와 상담소 브랜딩 | 상담 분야에 맞는 정보를 추가하고, 화면과 결과지에 상호·로고를 적용함 |
| Windows 설치 파일과 사용안내서 | Excel 설치나 웹 접속 없이 가게 PC에서 실행할 수 있도록 제공함 |

2026.10.2. 의뢰인 전달용 설치 파일과 사용안내서를 준비하고, 2026.10.4. v0.1.2 설치 파일을 생성함. 프로그램은 현재 상담 현장에서 사용 중임.

### 5-2. 의뢰인 반응

- 의뢰인은 요청하지 않았던 화면·결과물 정리와 연도별 한자 간지 표시가 상담의 전문성을 높였다고 평가함.
- 결과지를 저장해 전달할 수 있게 되면서, 기존에 그래프를 직접 그려 보내던 작업보다 전달에 드는 시간이 크게 줄었다고 피드백함.
